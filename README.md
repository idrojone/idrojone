## 🚀 Proyectos destacados

### 🏟️ [PoliCourt](https://github.com/idrojone/PoliCourt)

Plataforma de gestión deportiva con arquitectura de **microservicios**: gestión de clubes, pistas y usuarios, flujo de reservas con reglas de negocio y **pagos integrados con Stripe** (checkout + webhooks). Monorepo con separación por capas (presentación → aplicación → dominio → infraestructura) y migraciones gestionadas con Flyway.

`Java 21` · `Spring Boot` · `Spring Security + JWT` · `PostgreSQL` · `Flyway` · `FastAPI` · `React + TypeScript` · `Vite` · `Stripe` · `Docker`

### 🗃️ [Task API](https://github.com/idrojone/todo-task)

API de gestión de tareas **GraphQL** diseñada con **Clean Architecture** y **Domain-Driven Design**: paginación avanzada, soft-deletes, transacciones en MongoDB y despliegue preconfigurado con Docker Compose.

`Java` · `Spring Boot` · `GraphQL` · `MongoDB` · `Clean Architecture` · `DDD` · `Docker`

### 🎸 [Melodía Vintage](https://github.com/idrojone/melodia-vintage-framework)

Marketplace de instrumentos musicales de segunda mano: búsqueda avanzada por tipo, marca, precio y ubicación, **mapa interactivo**, sistema de valoraciones, perfiles de usuario y galería de fotos.

`PHP` · `JavaScript` · `HTML` · `CSS`

### 🛠️ [RISC-V Assembly Playground](https://github.com/idrojone/assembly-riscv)

Entorno listo para practicar **ensamblador RISC-V** con el simulador RARS: plantillas base, scripts de ejecución para Windows/Linux, ejemplos y ejercicios resueltos (aritmética, syscalls y traducción a código máquina).

`Assembly RISC-V` · `PowerShell` · `Batch`
